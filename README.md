# TopoPlotting

An interactive browser tool for exploring terrain contours, roads, relief, and print-ready map crops around San Diego, the San Francisco Bay Area, and Houston.

## Hosted features

- Pan and scroll zoom
- Adjustable land and bathymetric contour intervals
- Dynamic contour density and physical pen widths
- Mission Valley, San Diego coast, San Francisco Bay Area, and Houston datasets
- PNG, SVG, STL, crop JSON, and ordered centerline exports

The one-click sliced Bambu A1 package is available only in the local desktop version because it uses a local conversion service.

## Data

Terrain sources and dates are shown in the viewer. Road overlays are © OpenStreetMap contributors. The hosted configuration omits the private selected-location marker and its saved view.
